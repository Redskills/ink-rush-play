# Ink Rush

A keyboard timing game set inside the Bitcoin chart, 2008 → 2026.

Throw the INK token at each candle and press the arrow shown **exactly** when it reaches
the tip of the wick. Bull runs speed everything up, PANIC SELL breaks the rhythm, PUMP IT
lets you spam ↑ for compounding gains, and real crypto events (Pizza Day, Ethereum,
Powell, COVID, Tesla, FTX) hit the market as you go.

**Play: https://redskills.github.io/ink-rush-play/**

Arrows or ZQSD · Esc pause · M mute · R restart · T tuning panel.
One HTML file, no dependencies, no build step.
